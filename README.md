# Pocket Wallet

Некастодиальный криптокошелёк для **Windows** и **Android**: 291 актив в 11 сетях (Bitcoin, Ethereum, TRON, Solana, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, Litecoin). Ключи создаются и хранятся только на устройстве.

## Скачать

Откройте раздел **[Releases → Latest](../../releases/latest)** и скачайте:

- **Windows** — `Pocket-Wallet-<версия>-setup.exe`, запустите установщик.
- **Android** — `Pocket-Wallet-<версия>.apk`, откройте файл на телефоне и разрешите установку из этого источника.

Установленное приложение само находит новые версии и предлагает обновиться.

## Безопасно

- Секретная фраза из 12 слов — единственный ключ к средствам. Запишите её на бумаге и никому не показывайте.
- Обновления проверяются по контрольной сумме SHA-256, APK подписан одним и тем же ключом.
- Учебный проект без независимого аудита: храните только небольшие суммы.
